# blog-app

使用 Vue3 + TypeScript + Vite + Pinia + Router + Ajax 重构之前使用 WordPress 开源博客框架搭建的博客：http://www.fflamingo.top

## 进度

### day 5

Vue3 + TS + Pinia + Router + Ajax ，实现简易博客框架(主页、文章列表、文章详情页)

### day 6

1. 模拟博客的导航栏实现 NavBar 组件
2. 实现网页的明暗切换
3. 通过 HomeView.vue 组装组件，使用路由填充到App.vue
4. 将 Ajax 逻辑独立成可复用 Composable

### day 7

1. 分功能整理文件结构
2. 实现 HomePage、Title、SubTitle、LinkBox 组件，丰富博客主页内容(背景图、博客主页标题、联系链接块)
3. 实现 NightStylebutton 组件，美化明暗主题切换按钮
4. 统一页面部分 CSS 样式颜色
